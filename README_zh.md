# 关于负债不得不在地下城打工这件事 (Dungeon Debt Story)

[English](README.md) | [简体中文](README_zh.md)

## 介绍与项目想法

这是一个完全由 AI 开发的 RPG 游戏项目。

**这个项目的想法：**一个完全用 AI 开发游戏的项目，想要试试 AI 在游戏开发方面的能力，同时将自己的一些小小的创意和想法快速变成现实。

## 游戏内容与世界观

本作是一款结合了“地牢探索”、“回合制战斗”与“模拟经营”的角色扮演游戏。玩家扮演一名背负巨额债务的主角，为了偿还欠款，不得不踏入充满未知与危险的地下城进行“打工”探索。

- **动态剧情与多结局**：序章至终章的完整剧情线，伴随角色好感度与道德值系统。你的每一次选择都可能导致 5 种截然不同的结局（普通结局、英雄结局、反派结局、逃亡结局、牺牲结局）。
- **地下城生态系统**：包含森林、火山、冰窟等多种主题的地下城。每个主题拥有独特的环境减益效果、专属怪物（如火属性免疫怪物）、隐藏陷阱和随机事件。
- **深度战斗体验**：引入 MP/HP 双轨制，包含物理/魔法主动技能与被动增益，属性克制（火克冰等）系统，以及包含多阶段变形机制的强大 Boss 战。
- **多元经济生存**：除了打怪爆金币，还包含城镇打工、商铺投资、黑市借贷与债务谈判系统，还原真实的“还债生存”压力。

## 技术架构与软件方案

本项目采用现代化的前端与桌面端技术栈构建，确保了流畅的跨平台体验：

- **核心语言**：[TypeScript](https://www.typescriptlang.org/) - 提供完善的类型推导与系统模型定义（如 `NPC.ts`, `DungeonTheme.ts`）。
- **用户界面**：[React 18](https://react.dev/) + [React Router](https://reactrouter.com/) - 结合现代化 Hooks 构建响应式游戏视图与动态剧情对话组件（StoryDialog）。
- **状态管理**：[Zustand](https://github.com/pmndrs/zustand) - 轻量级全局状态管理，负责驱动核心的 `gameStore`，无缝衔接战斗、经济与故事系统。
- **UI 与样式**：[Tailwind CSS](https://tailwindcss.com/) - 原子化 CSS 框架，快速构建各种主题感知的游戏面板与动画界面。
- **桌面端封装**：[Electron](https://www.electronjs.org/) + [electron-builder](https://www.electron.build/) - 实现 Windows/Mac/Linux 跨平台打包。
- **构建工具**：[Vite](https://vitejs.dev/) - 极速的冷启动与热更新体验。

### 核心系统设计 (Systems)
- `StorySystem`: 剧情节点管理，基于游戏内“天数”自动触发事件。
- `BattleSystem`: 战斗状态机，处理技能冷却、回合判定、伤害结算与特效动画。
- `ThemeSystem`: 地下城环境系统，动态应用环境光、粒子效果、属性减益及背景音乐。
- `RelationshipSystem`: 复杂的 NPC 好感度计算与互动网络。

## 创意与扩展想法 (Ideas in Documentations)

在项目的设计文档中，我们记录了许多由 AI 与开发者碰撞出的火花与创意：

1. **环境与战斗的深度互动**：地下城的环境（如火山的每回合扣血、森林的视野受限）与战斗系统紧密结合，玩家可以利用场景陷阱对 Boss 造成巨额伤害。
2. **真实的人性抉择**：在沉重的还款压力下，玩家会被迫在“道德”与“金钱”间做出选择，是牺牲同伴换取赏金，还是不顾一切守护契约师莉莉？
3. **“打工”与“投资”的金融模拟**：引入“期货/股票”等简单的金融市场和“高利贷”设定，如果打怪太累，也许能在酒馆靠赌博或者投资商铺实现财务自由（或万劫不复）。
4. **主题化沉浸式 UI (Theme-Aware UI)**：不仅是背景图的更换，当玩家进入不同地下城时，整个 UI 面板的主色调、边框、背景音乐甚至按钮样式都会发生动态变化，带来极致的沉浸感。
