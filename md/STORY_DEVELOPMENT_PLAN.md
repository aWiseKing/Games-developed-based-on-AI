# 游戏主线故事编写与开发方案

## 项目名称：关于负债不得不在地下城打工这件事

## 一、故事背景设定

### 1.1 世界观
在一个剑与魔法的世界中，地下城不仅是冒险者的圣地，更是底层民众赖以生存的工作场所。这里的怪物会掉落金币、材料和装备，但同时也充满危险。

主角原本是一个小镇青年，靠着小聪明和骗术在底层社会谋生。然而骗术败露，被地下城公会的债主格雷顿抓住。格雷顿没有直接将主角送去坐牢，而是提出了一个"交易"：主角必须成为另一个负债者——少女莉莉的担保人。莉莉因家人生病而借债，却无力偿还。如果主角不能在30天内还清10000金币，不仅主角自己要失去自由，莉莉也会被卖入地下城最深处充当祭品。

就这样，一个骗子和一个弱女子被绑定在了一起，为了生存而不得不进入地下城打工还债。

### 1.2 核心冲突
- **双重债务**：不仅要还自己的债，还要对莉莉的命运负责
- **时间压力**：30天期限，每天只能行动3次
- **道德困境**：曾经的骗子是否愿意为陌生人拼命
- **伙伴关系**：与莉莉的关系会影响游戏进程和结局
- **生存压力**：战斗会消耗生命值，需要合理规划
- **身份认同**：从自私自利的骗子到负责任的担保人

## 二、主线剧情大纲

### 序章：天降横祸（第1-3天）
**目标**：让玩家熟悉基础操作，了解游戏机制，建立主角与莉莉的关系

**剧情**：
- **开场**：主角在小镇酒馆行骗，用假药卖给商人，被债主格雷顿当场抓住
- **惩罚**：格雷顿没有送主角去坐牢，而是提出了"担保人计划"
- **初次见面**：主角第一次见到莉莉——一个瘦弱的红发少女，因为给病重的母亲买药而欠下债务
- **强制绑定**：格雷顿宣布主角成为莉莉的担保人，两人命运绑定
- **最后通牒**：30天内必须还清10000金币，否则两人都会被送往地下城深处
- **被迫合作**：莉莉虽然害怕主角（知道他是骗子），但为了生存不得不跟随
- **首次探险**：主角和莉莉一起进入地下城第一层

**关键场景**：
- **酒馆对峙**：格雷顿揭露主角的骗局，全场哗然
- **地牢相见**：在格雷顿的地牢中，主角第一次见到莉莉
- **契约仪式**：魔法契约将两人的命运绑定，一人死亡另一人也会受到重创
- **首次合作战斗**：莉莉虽然是普通人，但懂得一些基础治疗

**教学点**：
- 基础战斗操作
- 伙伴系统（莉莉会在非战斗时提供治疗支持）
- 债务和担保系统介绍
- 时间流逝机制
- 好感度系统（莉莉对主角的信任度）

### 第一章：初入地下城（第4-10天）
**目标**：建立基础循环，了解游戏节奏，发展主角与莉莉的关系

**剧情**：
- 主角和莉莉逐渐适应地下城生活，开始建立基本的合作关系
- 莉莉展现出治疗天赋，让主角意识到她的价值
- 在小镇酒馆听到关于"地下城深处有宝藏"的传闻，但莉莉对此感到害怕
- 遇到其他冒险者，得知有人靠地下城发了财，也有人永远留在了里面
- 汤姆（莉莉的青梅竹马）出现，警告主角不要欺负莉莉，并提供帮助
- 主角开始思考：是稳扎稳打慢慢还债，还是冒险深入追求高回报？莉莉会支持哪种选择？

**关键事件**：
- 解锁第2-3层地下城
- 首次遭遇精英怪，莉莉的治疗救了主角一命
- 遇到商人NPC，了解投资系统
- 解锁技能系统
- 莉莉的好感度事件（分享食物、聊天、共同面对危险）

**分支选择**：
- **保守路线**：每天只探索1-2层，确保莉莉的安全，莉莉好感度+，但收入较低
- **激进路线**：尝试挑战更高层数，莉莉害怕但跟随，高风险高回报，莉莉好感度波动
- **利用路线**：把莉莉当作工具人，只关心赚钱，莉莉好感度--，但收入最大化

**莉莉相关剧情**：
- **第5天**：莉莉的噩梦（梦到母亲），主角可以选择安慰她或无视
- **第7天**：汤姆邀请莉莉离开主角，莉莉的选择取决于好感度
- **第9天**：莉莉的生日，主角可以选择送礼物或忘记

### 第二章：暗流涌动（第11-20天）
**目标**：引入更多系统和支线，增加游戏深度，揭示格雷顿的真实目的

**剧情**：
- 主角发现地下城中有神秘组织在活动，似乎在寻找特定的人
- 暗影商人出现，暗示格雷顿在"养肥"莉莉，主角只是被利用的工具
- 莉莉开始出现奇怪的梦境，梦到地下城深处有东西在召唤她
- 玛格丽特透露格雷顿曾经也有妻子和孩子，暗示他失去过重要的人
- 得知第10层有一个传说中的BOSS，击败它能获得巨额奖励，但格雷顿似乎不希望有人到达第10层
- 主角必须在信任和怀疑之间做出选择：相信格雷顿，还是相信暗影的警告？

**新系统解锁**：
- 黑市借贷系统（高利息）
- 装备强化系统
- 更多技能解锁
- 任务系统（支线任务）
- 莉莉的治疗能力升级（好感度高时解锁更强力的治疗）

**关键选择**：
- **是否借高利贷**：暗影提供，可以快速获得资金，但利息会不断累积，且格雷顿会不高兴
- **是否调查格雷顿**：花费时间和金钱，可能发现真相，但也可能打草惊蛇
- **是否让莉莉独自休息**：莉莉精神疲惫，让她休息会错过一些探险，但保护她的精神状态

**莉莉相关剧情**：
- **第13天**：莉莉发现格雷顿的书房有她母亲的画像，产生怀疑
- **第16天**：莉莉被神秘人跟踪，主角可以选择保护她或无视
- **第19天**：莉莉的能力突然增强，但她感到不安

### 第三章：真相浮现（第21-28天）
**目标**：推动主线剧情，揭示隐藏秘密，主角必须做出命运抉择

**剧情**：
- **第21天**：主角发现莉莉的血脉特殊，她是古代契约师的后裔，血液有强大的魔力
- **第23天**：追踪线索发现格雷顿的阴谋：他需要一个契约师后裔的灵魂来复活他的妻子，而莉莉正是完美的人选
- **第25天**：格雷顿坦白一切：他的妻子死于地下城事故，他一直在寻找复活她的方法，莉莉是他最后的希望
- **第26天**：莉莉得知真相，精神濒临崩溃，主角必须安抚她或利用她
- **第28天**：最后的机会，主角必须在还债和保护莉莉之间做出选择，同时还要面对格雷顿的最终通牒

**重大剧情分支**：

**分支A：专心还债，牺牲莉莉**
- 无视莉莉的命运，专注打工赚钱
- 在最后一天还清债务，获得自由
- 莉莉成为祭品，格雷顿的妻子复活，但格雷顿也陷入疯狂
- 主角虽然自由，但背负着出卖莉莉的罪孽

**分支B：调查真相，保护莉莉**
- 花费时间和金钱调查地下城的秘密
- 发现格雷顿的计划，必须在第30天前阻止仪式
- 与格雷顿决裂，开启最终战斗
- 必须在还债和对抗格雷顿之间分配资源

**分支C：与格雷顿合作，寻找第三条路**
- 利用格雷顿的资源快速积累财富
- 同时暗中寻找拯救莉莉的方法
- 高风险高回报，如果失败莉莉必死
- 最终可能找到不需要牺牲莉莉就能复活格雷顿妻子的方法（完美结局的前置条件）

**分支D：背叛所有人**
- 利用格雷顿和莉莉的信任，为自己谋取最大利益
- 甚至可以取代格雷顿成为新的地下城统治者
- 最终成为新的反派

### 终章：最后的选择（第29-30天）
**目标**：多重结局，根据玩家选择决定最终命运

**剧情高潮**：
- 最后一天即将到来
- 根据之前的选择，主角面临不同的最终挑战
- 必须做出最后的抉择

## 三、角色设定

### 主角（玩家）
- **默认名**：勇者（可自定义）
- **背景**：小镇青年，靠骗术为生，因诈骗失败被抓住
- **性格**：最初自私、狡猾，但在与莉莉的相处中逐渐改变
- **成长**：从只为自己着想的骗子，到愿意为守护他人而战的担保人
- **特殊状态**：与莉莉有魔法契约绑定，命运相连

### 主要NPC

#### 1. 债主 - 格雷顿
- **身份**：地下城公会的高阶成员，也是地下城的实际掌控者之一
- **性格**：冷酷、精于算计，但也有自己的原则。对主角的骗术嗤之以鼻
- **秘密**：与地下城深处的黑暗势力有联系，需要活人献祭来维持某种仪式
- **作用**：推动主线剧情，强迫主角成为担保人，观察主角是否会改变
- **对主角的态度**：既鄙视主角的骗术，又好奇他是否会在绝境中成长

#### 2. 被担保人 - 莉莉（核心角色）
- **身份**：17岁的红发少女，原本是小镇药剂师学徒
- **背景**：母亲重病，为买药借了高利贷，结果母亲去世，债务却越滚越大
- **性格**：善良、坚强但胆小，擅长治疗和草药知识
- **能力**：战斗中无法攻击，但可以在非战斗时为队伍治疗（每日限3次）
- **与主角的关系**：
  - 初期害怕主角（知道他是骗子），但不得不依赖他
  - 中期逐渐建立信任，开始真正合作
  - 后期可能成为主角改变的关键
- **重要性**：
  - 如果莉莉死亡或精神崩溃，主角也会受到重创
  - 莉莉的好感度会影响结局
  - 某些结局中莉莉的命运是判定条件之一

#### 3. 酒馆老板 - 玛格丽特
- **身份**：小镇酒馆的老板娘，格雷顿的前妻（已离婚）
- **性格**：热情、消息灵通，同情负债者，暗中帮助主角和莉莉
- **作用**：提供任务信息、传闻、支线任务，知道格雷顿的一些秘密

#### 4. 神秘商人 - 暗影
- **身份**：黑市商人，似乎是格雷顿的对头
- **性格**：神秘、亦正亦邪，对主角的骗术很欣赏
- **作用**：提供高风险高回报的交易、隐藏物品，有时会提供格雷顿的情报

#### 5. 其他负债者
- **战士汤姆**：正直但运气不好，莉莉的青梅竹马（暗恋莉莉）
- **法师艾琳**：聪明但有些自私，知道格雷顿的一些内幕
- **盗贼杰克**：狡猾，知道如何逃避债务，但警告主角不要信任格雷顿
- **作用**：提供支线任务、合作或竞争机会，有的会帮助莉莉

### 反派角色

#### 地下城领主 - 莫拉格斯
- **身份**：第10层的最终BOSS
- **背景**：曾是古代王国的将军，被黑暗力量腐化
- **目的**：收集地下城中的灵魂和财富
- **关系**：与债主格雷顿有秘密协议

## 四、剧情分支与选择系统

### 4.1 道德值与好感度系统
游戏中玩家的选择会影响两个核心数值：

**声望值（道德值）**：
- **正直**：帮助他人、遵守承诺、保护莉莉 → 声望+
- **中立**：只顾自己 → 声望不变
- **邪恶**：欺骗、伤害他人、牺牲莉莉 → 声望-

**莉莉的好感度**：
- **信任**：主动保护莉莉、分享食物、诚实沟通 → 好感度+
- **一般**：正常合作 → 好感度不变
- **恐惧/厌恶**：忽视莉莉、欺骗她、让她陷入危险 → 好感度-

影响：
- NPC对主角的态度
- 莉莉在关键时刻的行为（低好感度时可能背叛主角）
- 可接取的任务类型
- 结局走向（莉莉是否愿意和主角一起离开）

**莉莉状态**：
- 莉莉有独立的HP和精神值
- 如果莉莉HP归零，主角会受到契约反噬（失去50%HP）
- 如果莉莉精神值过低，可能会崩溃或逃跑

### 4.2 关键选择点

**选择点1：莉莉的求助（第3天）**
- 莉莉请求主角把最后一瓶治疗药水给她的青梅竹马汤姆
- 选项A：给莉莉（药水-1，莉莉好感度++，声望+）
- 选项B：拒绝，自己留着（药水保留，莉莉好感度-，声望-）
- 选项C：提出条件，让汤姆欠你人情（获得任务，莉莉好感度--，声望--）

**选择点2：黑市借贷**
- 第12天，资金紧张时遇到暗影商人
- 选项A：借高利贷（立即获得2000金币，利息每日10%）
- 选项B：拒绝（继续正常游戏）
- 选项C：以莉莉为抵押借款（获得3000金币，莉莉好感度---，解锁隐藏路线）

**选择点3：保护莉莉（第15天）**
- 遭遇精英怪物，莉莉被抓住
- 选项A：拼命救她（战斗难度增加，莉莉好感度+++，可能受伤）
- 选项B：谈判周旋（消耗金币，莉莉好感度+）
- 选项C：抛弃她逃跑（莉莉好感度---，声望---，莉莉死亡或重伤）

**选择点4：发现真相（第22天）**
- 发现格雷顿的阴谋：他需要莉莉作为祭品，主角只是被利用来"养肥"莉莉的
- 选项A：对抗他（开启战斗路线，保护莉莉）
- 选项B：合作，但要求放过莉莉（格雷顿同意，但要求更多金币）
- 选项C：假装不知道，继续赚钱（保守路线，但莉莉必死）

**选择点5：最终抉择（第29天）**
- 最后一天，必须做出选择
- 选项A：还清债务，带莉莉离开（普通结局）
- 选项B：击败莫拉格斯和格雷顿，成为英雄（英雄结局）
- 选项C：取代格雷顿，控制地下城（反派结局，莉莉会成为你的"助手"或反抗你）
- 选项D：抛弃莉莉，独自携款潜逃（逃亡结局，莉莉成为祭品）
- 选项E：牺牲自己，让莉莉获得自由（牺牲结局）

## 五、多结局设定

### 结局A：各自的自由（普通结局）
**条件**：还清10000金币债务 + 莉莉存活 + 莉莉好感度>=30
**剧情**：主角终于还清了债务，莉莉也得救了。两人站在地下城出口，阳光洒在疲惫但释然的脸上。莉莉感谢主角的保护，但选择各自开始新生活。
**CG**：主角和莉莉并肩走出地下城，然后朝不同方向走去，挥手告别。

### 结局B：守护的誓言（英雄结局）
**条件**：还清债务 + 击败第10层BOSS莫拉格斯 + 击败格雷顿 + 莉莉好感度>=60 + 莉莉存活
**剧情**：主角不仅还清债务，还揭露了格雷顿的阴谋，拯救了包括莉莉在内的所有负债者。主角从骗子蜕变成了真正的英雄，莉莉成为了主角最重要的伙伴。
**CG**：主角和莉莉站在小镇广场上，周围是欢呼的人群，格雷顿被卫兵带走。莉莉微笑着看着主角。

### 结局C：黑暗中的羁绊（反派结局）
**条件**：未还清债务或还清债务 + 击败莫拉格斯 + 与格雷顿合作/取代他 + 声望值低
**剧情**：主角选择成为新的地下城掌控者。莉莉虽然被救，但对主角充满恐惧，但已经无法离开。主角拥有权力，却失去了最重要的东西——莉莉的信任。
**CG**：主角坐在王座上，莉莉被锁链束缚在旁边，眼神空洞。主角伸手想触碰她，却被她躲开。

### 结局D：自私的逃亡（逃亡结局）
**条件**：未还清债务 + 最后一天选择逃跑 + 抛弃莉莉
**剧情**：主角带着剩余的金币逃离了小镇，留下莉莉成为祭品。虽然暂时逃脱，但债务的阴影和良心的谴责永远笼罩着主角。
**CG**：主角在夜色中逃离，回头看了一眼小镇，隐约听到莉莉的哭喊声，然后咬牙消失在黑暗中。

### 结局E：债务的代价（坏结局）
**条件**：第30天结束时金币为负数或债务未还清 + 莉莉死亡或成为祭品
**剧情**：主角无法还清债务，莉莉成为祭品，主角也被格雷顿抓去当苦力。两个被命运捉弄的人，最终都成为了地下城的牺牲品。
**CG**：主角在黑暗的矿洞中挖矿，旁边是莉莉的遗物（一条红发带），眼神绝望。

### 结局F：永远的羁绊（真结局/隐藏结局）
**条件**：还清债务 + 击败莫拉格斯 + 击败格雷顿 + 莉莉好感度>=80 + 莉莉存活 + 完成所有支线任务 + 莉莉专属剧情线完成
**剧情**：主角不仅拯救了小镇，还改革了地下城制度。更重要的是，主角和莉莉在共同经历中建立了超越生死的羁绊。两人选择一起离开，开始新的生活。
**CG**：主角和莉莉手牵手走出地下城，阳光温暖。莉莉靠在主角肩膀上，两人相视而笑。

### 结局G：最后的守护（牺牲结局）
**条件**：最后一天选择牺牲自己 + 莉莉好感度>=50
**剧情**：主角意识到只有自己的死才能解除契约，让莉莉获得自由。主角在最后一天与格雷顿同归于尽，用生命换取莉莉的未来。
**CG**：莉莉跪在主角身边哭泣，主角微笑着擦去她的眼泪，然后化作光芒消散。多年后，莉莉成为了一名著名的治疗师，救助了无数人。

```typescript
// 结局判定
function determineEnding(player: Player): Ending {
  if (player.debt <= 0 && player.gold >= 0) {
    if (player.reputation >= 80 && player.completedQuests.length >= 10) {
      return 'perfect' // 真结局
    } else if (player.reputation >= 50) {
      return 'hero' // 英雄结局
    } else {
      return 'normal' // 普通结局
    }
  } else {
    if (player.defeatedBoss) {
      return 'villain' // 反派结局
    } else if (player.escaped) {
      return 'escape' // 逃亡结局
    } else {
      return 'bad' // 坏结局
    }
  }
}
```

## 九、总结

本方案为"关于负债不得不在地下城打工这件事"提供了完整的主线故事框架，包括：

1. **6个章节**的完整剧情流程
2. **7种不同结局**的多结局系统（从普通结局到真结局）
3. **丰富的角色**设定和人物关系，核心角色莉莉贯穿始终
4. **双重绑定机制**：债务压力 + 担保责任
5. **道德选择**系统影响剧情走向
6. **伙伴成长**：莉莉从恐惧到信任的心路历程
7. **详细的开发**时间表和技术方案

### 核心设计亮点：

**创新的担保人设定**：
- 主角不是单纯为自己还债，而是要保护另一个负债者
- 魔法契约绑定两人的命运，增加情感张力
- 莉莉的存在迫使主角从自私走向担当

**复杂的人物关系**：
- 格雷顿既是反派，也是失去妻子的可怜人
- 莉莉既是受害者，也是古代契约师的后裔
- 主角从骗子转变为守护者

**多重情感线**：
- 主角和莉莉的信任建立过程
- 格雷顿对妻子的执念与疯狂
- 汤姆对莉莉的暗恋与主角的竞争

**道德困境设计**：
- 是否牺牲莉莉来换取自己的自由？
- 是否相信格雷顿还有人性？
- 是否愿意为了守护他人而牺牲自己？

通过债务压力和道德选择的双重驱动，创造出一个既有挑战性又有深度的游戏体验。玩家不仅要考虑如何赚钱还债，还要面对人性的考验，更重要的是，要思考什么是真正的责任与守护。最终的选择将决定主角和莉莉共同的命运。
